# DiskScope 1.0.0

DiskScope 1.0.0 is the first production release of the local Windows storage analyzer built around one principle: finding large files should not encourage risky deletion.

## What is included

- Live, cancellable scans of drives and folders.
- File and nested-folder size analysis.
- Search, category filters, size thresholds, and sortable results.
- Clear safety guidance with stronger warnings for application data, executables, and unknown items.
- Hard protection for detected Windows, boot/recovery, protected-volume, and critical system files.
- Windows-native open, reveal, properties, clipboard, and Recycle Bin actions.
- Automatic Windows app-theme following with live updates and optional light/dark overrides.
- Live switching of the complete interface between German and English, initially following the Windows language.
- Unified hard-drive-and-magnifier branding across the interface, executable, installer, and shortcuts.
- Self-contained x64 installer and portable archive.

## Important safety note

DiskScope classifications are cautious heuristics, not guarantees. Back up important data, inspect files before removal, and use Windows uninstallation or maintenance tools for software and operating-system components.

DiskScope refuses Recycle Bin actions on network and other locations where Windows cannot guarantee a recoverable local Recycle Bin.

## Privacy

DiskScope performs scans locally and includes no telemetry, cloud service, account, analytics, advertising, or automatic network request.
